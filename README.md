# playwright-typescript-learning

My learning repo for Playwright test automation in TypeScript (22 Nov 2026 to 5 Feb 2027).
Every topic has its own folder with runnable tests and a short README.

## How to run

1. Install Node 26 LTS.
2. `npm install`
3. Copy `.env.example` to `.env` and fill in values.
4. `npx playwright test`
